# 设备产品参考图

这些缩略图用于设备型号识别，来源为对应品牌的公开产品页面。图片版权归各自权利人，未声明为开放许可，不适用本项目源代码许可。

每个具体型号的原始图片 URL、产品页面、核对日期、原图及打包图 SHA256、尺寸和处理说明，完整保存在 `../../equipment-photo-data.js`。应用「规格与来源 → 产品图片来源与说明」显示对应出处。

处理仅限裁去空白边缘、缩小和转换 WebP；没有生成或改造产品结构。同型号的多个卡口版本共享产品外观参考图，卡口、重量和画幅规格仍独立保存。套机镜头、配件或颜色不代表用户购买的版本。

应用运行时只读取这些本地资源，不抓取官网或下载产品图片。新增图片时须核对具体型号、保留来源与权利说明，并更新资源校验和离线缓存清单。普通用户导入的资料包不能声明内置图片身份或开启未核实的网络图片下载。
